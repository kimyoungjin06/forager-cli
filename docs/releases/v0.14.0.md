The tagged source includes tmux-backed agent sessions and worktrees, Offdesk
task/approval/runtime records, Telegram inspection and bound workflow actions,
closeout and review receipts, and adaptive-wiki candidate/projection tools.
Website workspace routes use samples unless local exports and an action bridge
are separately configured. Optional arbitrary-command Telegram dispatch is
disabled by default. A result receipt records review state, not correctness.

The [original tagged release notes, preserved verbatim](../assets/history/v0.14.0-release-notes.txt)
retain the contemporary capability inventory, reported test counts and required
release checks. Read them as a historical account of that tag. A workflow being
configured does not establish that every CI job passed; inspect the actual run
when that result matters.

The [2026-11-04 core checkpoint](../offdesk-operation-status.md#post-release-core-source-checkpoint-2026-11-04)

the installed command's `--help` before applying a newer example.

## Compatibility and installation

`forager` is the primary command; `aoe` is a legacy alias. Linux normally uses
`$XDG_CONFIG_HOME/forager` or `~/.config/forager`; macOS uses `~/.forager`.
Use `forager doctor` to inspect active compatibility paths before migration.
See [Installation](../installation.md) for checksums, receipts and the operator
bundle, and [Operation Status](../offdesk-operation-status.md) for qualification
boundaries.
